## 🎯 機能要件

### 1. 認証機能（SC-01）

#### 1.1 ログイン

**機能概要**:
- Supabaseのメール認証を使用
- 初回起動時のみログイン画面を表示

**要件**:
- [ ] メールアドレスとパスワードでログイン
- [ ] 「アカウント作成」リンク表示
- [ ] パスワードリセット機能
- [ ] 自動ログイン（トークン保存）

**画面要素**:
- メールアドレス入力欄
- パスワード入力欄
- ログインボタン
- 新規登録リンク
- パスワードを忘れた方リンク

#### 1.2 アカウント登録

**要件**:
- [ ] メールアドレス・パスワード入力
- [ ] メール確認リンク送信
- [ ] 確認後ログイン可能

### 2. 勤務先管理機能（SC-03, SC-04）

#### 2.1 勤務先一覧表示（SC-03）

**機能概要**:
- 登録済みの勤務先を一覧表示
- 色分けで視覚的に識別

**要件**:
- [ ] 勤務先カード表示（店舗名・色・連絡先）
- [ ] タップで詳細・編集画面へ遷移
- [ ] 「＋」ボタンで新規登録
- [ ] 削除機能（スワイプまたは長押し）

**表示項目**:
- 店舗名（大きく表示）
- 店舗カラー（背景またはアクセント）
- 連絡先アイコン（電話・LINE・メール）
- 最終更新日時

#### 2.2 勤務先登録・編集（SC-04）

**機能概要**:
- 勤務先の詳細情報を入力・編集

**要件**:
- [ ] 店舗名入力（必須）
- [ ] 色選択（必須）
- [ ] 電話番号入力（任意）
- [ ] LINE ID入力（任意）
- [ ] メールアドレス入力（任意）
- [ ] 時給入力（任意・数値）
- [ ] 交通費入力（任意・数値）
- [ ] メモ欄（任意・複数行）
- [ ] 保存ボタン
- [ ] キャンセルボタン

**バリデーション**:
- 店舗名: 1文字以上、50文字以内
- 色: 必須選択（10色のプリセットから選択）
- 時給・交通費: 0以上の数値

**色プリセット**:
- 赤・青・緑・黄・紫・オレンジ・ピンク・水色・茶色・グレー

### 3. シフト管理機能（SC-02, SC-05）

#### 3.1 ホーム画面（SC-02）

**機能概要**:
- 月間カレンダー表示
- 登録済みシフトの可視化

**要件**:
- [ ] 月間カレンダー表示（table_calendar使用）
- [ ] 日付ごとにシフトドット表示（勤務先の色）
- [ ] 日付タップでシフト入力画面へ
- [ ] 既存シフトタップで編集画面へ
- [ ] 月切り替えボタン
- [ ] PDF出力ボタン（画面右上）

**表示仕様**:
- 1日に複数シフトがある場合、複数のドット表示
- ドットは勤務先の色で表示
- 当日は強調表示

#### 3.2 シフト入力画面（SC-05）

**機能概要**:
- 選択した日付のシフト詳細を入力

**要件**:
- [ ] 日付表示（変更不可）
- [ ] 勤務先選択（ドロップダウン）
- [ ] 開始時刻選択（タイムピッカー）
- [ ] 終了時刻選択（タイムピッカー）
- [ ] 休憩時間入力（任意・分単位）
- [ ] メモ欄（任意・複数行）
- [ ] 保存ボタン
- [ ] 削除ボタン（編集時のみ）
- [ ] キャンセルボタン

**バリデーション**:
- 勤務先: 必須選択
- 開始時刻: 必須
- 終了時刻: 必須（開始時刻より後）
- 休憩時間: 0以上の整数

**自動計算**:
- 勤務時間 = 終了時刻 - 開始時刻 - 休憩時間
- 収入見込み = 勤務時間 × 時給 + 交通費

### 4. PDF出力・共有機能（SC-06）

#### 4.1 PDF生成

**機能概要**:
- 選択期間のシフトをPDF化

**要件**:
- [ ] 期間選択（開始日・終了日）
- [ ] デフォルト: 来週1週間
- [ ] 勤務先フィルター（全て/個別選択）
- [ ] プレビュー表示
- [ ] PDF生成ボタン

**PDF仕様**:
- A4サイズ・縦向き
- タイトル: 「シフト希望表」
- 期間表示: 「2025年1月15日〜1月21日」
- 表形式:
  - 列: 日付・曜日・勤務先・時間帯・備考
  - 各勤務先を色分け（背景色）
- フッター: 生成日時・アプリ名

#### 4.2 共有機能

**機能概要**:
- 生成したPDFを外部アプリで共有

**要件**:
- [ ] 共有ボタン（OSのシェア機能を使用）
- [ ] 対応アプリ: LINE・メール・ファイルアプリ等
- [ ] ファイル名: `シフト希望_YYYYMMDD.pdf`

## 📊 ユースケース

### UC-01: 新規勤務先を登録する

1. ホーム画面で「勤務先管理」をタップ
2. 「＋」ボタンをタップ
3. 勤務先情報を入力
4. 「保存」をタップ
5. 勤務先一覧に追加される

### UC-02: シフトを入力する

1. ホーム画面のカレンダーで日付をタップ
2. シフト入力画面が開く
3. 勤務先を選択
4. 開始時刻・終了時刻を入力
5. 「保存」をタップ
6. カレンダーにドットが表示される

### UC-03: シフトをPDFで提出する

1. ホーム画面で「PDF出力」ボタンをタップ
2. 期間を選択（デフォルト: 来週）
3. 勤務先を選択（デフォルト: 全て）
4. プレビューを確認
5. 「共有」ボタンをタップ
6. LINEまたはメールアプリを選択
7. 宛先を選んで送信


## ⚠️ 制約・前提条件

1. **勤務先数**: 最大20件まで
2. **シフト期間**: 過去6ヶ月〜未来6ヶ月まで表示
3. **PDF出力**: 最大31日分（1ヶ月）
4. **同期**: Wi-Fi環境下を推奨（モバイル通信も可）
5. **対応端末**: Flutter対応端末（iOS 12+, Android 6+）
