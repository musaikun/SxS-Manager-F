## 🚧 Phase 2: 時間管理機能（次の優先）

### 2-1. 時間設定機能の拡充
**目的:** 個別・一括での時間入力を快適に

**実装内容:**
- [ ] 一括時間設定
  - 選択した複数日付に同じ時間を設定
  - UI: ShiftListScreen にチェックボックス追加
  - ファイル: `shift_list_screen.dart` の改修

- [ ] デフォルト時間設定
  - 店舗ごとのデフォルト時間を保存
  - 例: 「店舗A: 9:00-17:00」
  - ファイル: 新規 `default_time_provider.dart`

- [ ] 時間テンプレート
  - よく使う時間帯をプリセット保存
  - 例: 「早番: 9:00-13:00」「遅番: 17:00-21:00」
  - ファイル: 新規 `time_template_provider.dart`

**セッション分割案:**
```
セッションA: 一括時間設定（shift_list_screen.dart 改修）
セッションB: デフォルト時間機能（新規プロバイダー）
セッションC: テンプレート機能（新規画面）
```

**競合リスク:** 中（shift_list_screen.dart は既存ファイル）
**推奨:** セッションAを単独で完成させる

## 推奨する開発順序

### 優先度：高
1. **一括時間設定** → 既存機能の使い勝手向上
2. **デフォルト時間** → 入力の手間削減

### 優先度：中
3. **確認・提出画面** → ワークフロー完成
4. **時給計算** → 付加価値機能

### 優先度：低
5. **認証機能** → 個人利用なら不要
6. **管理者機能** → 組織利用時に検討

## セッション設計のポイント

### 🟢 安全な並行開発が可能
```

→ ディレクトリが完全分離 → 競合なし
```

```

→ 完成・テスト・マージ完了後
セッション2: 次の既存ファイル改修
```

