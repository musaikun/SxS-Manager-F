## 🔒 セキュリティ要件

### 認証・認可

1. **認証方式**
   - Supabase Auth（メール認証）
   - JWTトークンベース
   - トークン有効期限: 1週間

2. **パスワードポリシー**
   - 最小文字数: 6文字
   - 推奨: 8文字以上、英数字+記号

3. **セッション管理**
   - 自動ログイン: トークンをSecureStorageに保存
   - タイムアウト: なし（個人利用のため）

### データ保護

1. **暗号化**
   - 通信: HTTPS/TLS 1.3
   - ローカルストレージ: Isar（暗号化オプションあり）
   - トークン: SecureStorage（OS標準）

2. **RLS（Row Level Security）**
   - Supabaseで有効化
   - ユーザーは自分のデータのみアクセス可能

3. **APIキー管理**
   - `.env`ファイルで管理
   - Gitにコミットしない（.gitignore）
   - 公開リポジトリでは環境変数で注入

### 脆弱性対策

| 脅威 | 対策 |
|------|------|
| SQLインジェクション | Supabase RPC使用、ORMで自動エスケープ |
| XSS | Flutter（Dart）はデフォルトで安全 |
| CSRF | Supabase JWTトークン認証 |
| 中間者攻撃 | HTTPS強制、証明書検証 |
