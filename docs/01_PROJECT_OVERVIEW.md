# プロジェクト概要

## 📱 プロジェクト名

**S×S Manager（エスバイエス マネージャー）**

Shift × Schedule Manager - シフトとスケジュールを掛け合わせた管理アプリ

---

## 🎯 目的

複数のアルバイト先を掛け持ちする個人が、**シフト希望を効率的に管理・提出できる**アプリを開発する。

### 解決したい課題

1. **掛け持ちバイトの管理が煩雑**
   - 3〜5件の勤務先を紙やカレンダーアプリで別々に管理している
   - どの店舗にいつシフト提出したか忘れがち

2. **シフト提出が面倒**
   - 毎回LINEやメールで手入力している
   - フォーマットが統一されていない

3. **過去のシフトが振り返りにくい**
   - 勤務時間や収入の集計が手作業
   - データが散らばっている

---

## 👤 ターゲットユーザー

### プライマリーユーザー

**自分自身**（個人利用）

- 3〜5件のアルバイト先を掛け持ち
- 週単位でシフト希望を提出
- スマートフォンでの操作がメイン

### ユーザー像

- **年齢**: 20代（大学生・フリーター）
- **技術レベル**: 一般的なスマホユーザー
- **利用シーン**: 移動中・休憩時間・自宅
- **デバイス**: スマートフォン（Android/iOS）、たまにPC

---

## 📊 スコープ

### Phase 1（MVP）- 本プロジェクト

**個人用シフト管理・提出アプリ**

以下の機能に限定：

1. ✅ **勤務先管理**
   - 店舗情報の登録・編集・削除
   - 色分け表示

2. ✅ **シフト入力**
   - カレンダーで日付選択
   - 時間帯入力

3. ✅ **シフト提出**
   - PDF形式で出力
   - LINE/メール/外部システムに共有

4. ✅ **データ同期**
   - オフライン対応（ローカルDB）
   - クラウド同期（Supabase）
   - 複数端末対応

---

## 🎨 主要な価値提案

1. **一元管理**
   - すべての勤務先のシフトを1つのアプリで管理

2. **素早い提出**
   - 数タップでPDF生成→共有完了

3. **安心のバックアップ**
   - クラウド同期で機種変更時も安心
   - オフラインでも使える
